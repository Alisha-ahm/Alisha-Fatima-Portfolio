## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Alisha-ahm/Portfolio-2026.git

# Navigate into the project directory
cd Portfolio-2026

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified by Vite) in your browser.

### Building for Production

```bash
npm run build
```

The output will be generated in the `dist` folder, ready for deployment to Vercel, Netlify, or GitHub Pages.
